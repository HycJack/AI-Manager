## Parent

- #1 — AI-Manager: Kitter 功能移植

## What to build

前端删除确认：删除技能确认对话框，支持单选和多选删除。多选时保护内置技能（不允许删除）。

## Acceptance criteria

- [ ] 删除确认对话框（dialog）：显示将要删除的技能列表
- [ ] 单选删除：点击技能 → 删除按钮 → 确认对话框 → 删除
- [ ] 多选删除：多选技能 → 批量删除 → 确认对话框 → 删除
- [ ] 内置技能保护：多选时如果包含内置技能，不允许删除（提示）
- [ ] 删除后刷新列表
- [ ] 删除后 toast 通知
